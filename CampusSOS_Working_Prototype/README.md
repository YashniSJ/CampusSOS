# CampusSOS – Working Software Prototype

A front-end prototype for a college project: **Smart Campus Emergency Assistance System**.

## Features
- Student emergency reporting
- Emergency categories: medical, accident, fire, harassment, lost student, security
- Priority levels
- Location field + browser GPS capture
- Student report tracking
- Security/admin dashboard
- Status workflow: Reported → Assigned → Responding → Resolved
- Local browser storage using `localStorage`
- Responsive UI

## How to run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. Click **Report Emergency** and submit a demo incident.
4. Open **My Reports** to track it.
5. Open **Security Dashboard** to change the status.
6. Data remains in the same browser because this prototype uses localStorage.

## Important
This is a demonstration prototype, not a real emergency service. For a production system, add secure authentication, server-side database storage, authorization, audit logs, encryption, verified campus contacts, and proper emergency-service integration.
